# Customer Sales & Revenue Analysis

## Project Overview
This project analyses customer sales data to understand sales, profit, product and regional performance using Power BI.

## Tools Used
- Microsoft Excel
- Power BI
- GitHub

## Dashboard Features
- Total Sales
- Total Profit
- Total Orders
- Sales by City
- Sales by Product Category
- Sales by Payment Mode
- Monthly Sales Trend
- Sales by Region
- Product-wise Sales Analysis

## Dataset
The dataset contains customer orders, products, quantities, prices, discounts, sales, cost, profit, region and payment information.

## Files Included
- customer_sales_data.csv — Dataset
- sales executive.pbix — Power BI dashboard

## Key Insights
The dashboard helps identify sales trends, profitable areas, popular product categories and payment-mode performance.
